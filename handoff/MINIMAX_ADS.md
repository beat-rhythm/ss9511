作成日: 2026-09-22
前提文書: `HANDOFF.md`（2026-09-01 / YouTube チャンネル戦略分析）
対象動画: **「ヤンキーが運営する遊園地に行ってみた【天上…】」**（`HANDOFF.md` 未収録の新作）
データ取得日: 2026-09-22（YouTube Studio アプリのスクリーンショット / 公開から9日経過時点）

## 0. 確定している事実

> **MiniMax が自社のPRのために、ユーザーの動画を YouTube のインフィード広告等として出稿した。**
> **MiniMax からユーザーへの事前連絡・事後報告は一切ない。**

- 広告の**クリエイティブがユーザーの動画そのもの**
- 出稿者・支払者は **MiniMax**、目的は **MiniMax 自社のPR**（Hailuo の生成品質のショーケース）
- 広告をクリックした視聴者は**ユーザーの動画の視聴ページに着地** → **視聴回数はユーザーのチャンネルに入る**

Google Ads では**自分が所有していない公開動画にも広告を出稿できる**（動画URLを指定するだけでよい）。したがって無断出稿は技術的に可能であり、**視聴・再生時間・エンゲージメントはすべて動画の所有者＝ユーザー側に計上される**。実害がないどころか、他社予算で送客を受けている状態。

### 傍証

外部流入元に **`feishu.cn`（飛書 / Lark）が 7.6%** で出現している。飛書は中国テック企業の標準的な社内コラボレーションツールであり、**中国企業の社内でこの動画のリンクが共有されている**ことを示す。MiniMax は上海の企業であり、自社PR素材として社内流通している状況と整合する。

※ただし外部流入は全体の 0.3%（実数 約75視聴）に過ぎず、`feishu.cn` はそのうち 7.6%（**実数わずか6視聴程度**）。**定性的なシグナルとしては強いが、量としては無視してよい。**

## 2. 最重要の発見

### 2-1. 広告を除いても、自然流入が前作の4.6〜7.4倍出ている【本件で最大の good news】

広告分（90.3%）を完全に取り除いた**自然流入だけ**で、前作「全員柳沢」の同じ9日時点を大きく上回っている。

| | 全員柳沢（9日） | ヤンキー遊園地（9日・**広告除外**） | 倍率 |
|---|---|---|---|
| ブラウジング機能 | 約278 | **約2,050** | **7.4倍** |
| 自然流入 合計 | 約492※ | **約2,400** | **4.9倍** |

※柳沢の521視聴から外部29を除いた値

**これは「他社に視聴回数を水増しされた」話ではない。** 広告をすべて捨てても、このチャンネルの自然配信量は前作から桁が変わっている。

ただし**原因はまだ特定できていない**。可能性は3つあり、切り分けには日別データが要る（§5）。

| # | 仮説 | 検証方法 |
|---|---|---|
| A | 広告の大量視聴が推薦システムに「反応の良い動画」と学習させ、自然配信が増えた | 日別グラフで**広告開始日より後**にブラウジングが立ち上がっていれば A |
| B | 単にコンテンツが前作より強く、自力でブラウジングを獲得している | 広告開始**前**から既にブラウジングが伸びていれば B |
| C | 広告経由で登録した視聴者のホームフィードに出ている | 登録者数の増加時期と突き合わせ |

**A が正しかった場合、`HANDOFF.md` §5-1 の「探索フェーズは放置が正解」という結論に、「ただし外部から燃料を入れると加速する」という重要な但し書きが付く。** これはチャンネル戦略そのものを書き換える発見になりうるため、§5 の日別データ取得を最優先とする。

### 2-2. 広告流入は「視聴」を運ぶが「支持」を運ばない — ハイプがほぼゼロ

`HANDOFF.md` §3 の「瞬」と比較すると、異常な乖離が出る。

| | 瞬 | ヤンキー遊園地 |
|---|---|---|
| 視聴回数 | 約1,796 | **約25,000（約14倍）** |
| ハイプ | **4** | **3** |
| ハイプポイント | 3,360 | 2,520 |

**視聴回数が14倍なのに、ハイプは4 → 3 と、むしろ減っている。**

瞬と同率でハイプが発生していれば、22,575の広告視聴からは約50ハイプが出るはずだった。実際は全体で3。しかもその3は自然流入（約2,400）から出たと考えるほうが自然である。

> **結論: 広告経由の約22,575視聴から、ハイプはほぼ1件も発生していない。**

ハイプは視聴者が能動的に枠を消費して行う支持行動であり、**広告でクリックした視聴者は最後まで見ても「応援」はしない**。これは広告流入の質を測る、この動画で最も明確な指標になった。

**したがって: 視聴回数2.5万を「大成功」と読んではいけない。** `HANDOFF.md` §6 で7回繰り返した過剰帰属の、8個目の候補がここにある。

### 2-3. コンテンツの保持力は過去2作を明確に上回る

| | 全員柳沢 | 瞬 | **ヤンキー遊園地** |
|---|---|---|---|
| 尺 | 6:23 | 2:54 | **8:14** |
| 平均視聴時間 | 1:41 | 1:25 | **3:21** |
| 平均視聴率 | 26.4% | 48.8% | 40.6% |

**最も長い尺（8:14）で、最も長い平均視聴時間（3:21）を出している。** 柳沢の2.0倍、瞬の2.4倍。

しかもこの 40.6% は、**視聴の90.3%が広告流入である状態で出した数字**である。計算すると、仮に自然流入（9.7%）が維持率100%だったとしても、広告流入の維持率は 34.2% を下回れない:

```
0.903 × X + 0.097 × 1.00 = 0.406  →  X = 34.2%（下限）
実際には自然流入も100%ではないため、広告流入の維持率は 40% 前後と見てよい
```

**8分超の動画で、広告経由の視聴者が平均40%まで見ている。** これは `MINIMAX_ADS.md` 旧版で立てた「インフィード広告は自己選択クリックなので自然流入に近い挙動をする」という仮説を、実測で裏付けている。

#### `HANDOFF.md` §5-3 の処方は、この動画には適用しない

前セッションは柳沢について「弱点は維持率ではなく尺。3:30で切れ」と結論した。**この処方をヤンキー遊園地に横展開してはいけない。** 8:14という前作より長い尺で 40.6% を出せている以上、**長尺を保たせる作りが既にできている**。切る理由がない。

### 2-4. 唯一の明確な弱点はイントロ 0:30

| | 0:30 残存率 | YouTube判定 |
|---|---|---|
| 全員柳沢 | 52% | 「通常とほぼ同じ」 |
| **ヤンキー遊園地** | **55%** | **「通常を下回っています」** |

**数値は柳沢より高いのに、判定は悪化している。** YouTube の「通常」は**同程度の尺の動画群**との比較であり、8分超の動画は「長いと分かって選ばれる」ため 0:30 残存率の基準が高い。55% はその基準を下回る。

維持率カーブの形状:

```
0:00 → 0:30   100% → 55%    ← 唯一の弱点。ここだけが判定上「通常以下」
0:30 → 2:30    55% → 約33%   （緩やかな減衰）
2:30 → 8:14    33% → 約17%   ← 非常にフラット。形としては良い
```

後半のフラットさは柳沢（§2-2）と同じく良い形。**改善余地は最初の30秒に集中している。**

`HANDOFF.md` §5-3 では柳沢について「イントロは触る必要なし」と結論したが、**本作では逆にイントロが唯一の弱点**。ここを 55% → 65% に持ち上げられれば、全体が丸ごと持ち上がる。

※ただし、この 55% も**広告流入込みの数字**である。広告で来た視聴者が冒頭で離脱している可能性があるため、自然流入のみのイントロ残存率を確認するまで、内容の修正には着手しない（§5 を先に取る）。

### 2-5. CTR 4.3% は、分母が確定するまで判断に使えない

サムネイルのクリック率 4.3%、9日間で 0% → 約6.3% へ右肩上がり。数字だけ見れば柳沢（2.4%）からの大幅改善に見える。

**しかし分母が何かが未確定であり、現時点では前作と比較できない。**

YouTube Studio の「インプレッション」は、仕様上**広告のインプレッションを除外する**と理解しているが、本件のように広告が視聴の90%を占める状況では、実数で検算して確認すべきである。

#### 検算方法（インプレッション実数が取れれば1分で決着）

```
インプレッション実数 ≒ 54,000 前後
  → 広告は除外されている。4.3% は自然流入のみの CTR
     （自然流入クリック 約2,400 ÷ 0.043 ≒ 55,800）
     この場合、柳沢の2.4%からの改善は本物。非常に良い

インプレッション実数 ≒ 50万超
  → 広告インプレッションを含んでいる
     この場合 4.3% は広告の CTR に支配されており、前作とは比較不能
```

スクリーンショットでは視聴回数カード（2.5万）に隠れてインプレッション数が見切れている。**§5 の最優先項目。**

## 3. `HANDOFF.md` §7「14日後の判定基準」は、このままでは使用不可

流入の 90.3% が広告である以上、集計値はすべて広告に支配されている。

| 指標 | 合格ライン | 状態 |
|---|---|---|
| CTR | 5%以上 | **分母未確定（§2-5）。判定不能** |
| 平均視聴率 | 45%以上 | 40.6% だが**9割が広告流入の数字**。自然流入のみの値が未取得 |
| **34歳以下比率** | **0%より上** | **最も危険。下記** |

### 3-1. 34歳以下比率は、ほぼ確実に偽陽性を出す

`HANDOFF.md` §7 は「34歳以下比率が0%を超えること」を**移植成否の本丸**と位置づけた。メインチャンネルが35〜54歳男性に固着している構造を破れたかの直接証明だからである。

MiniMax のターゲティングは **AI動画生成に関心のある層**——相対的に若く技術志向の層に向く。そして**視聴の90.3%が広告**である。

> このまま視聴者タブを見れば、34歳以下比率はほぼ確実に0%を超える。
> しかしそれは**チャンネル分離の成果ではなく、MiniMax のターゲティング設定を見ているだけ**である。

**判定基準の中で最も重要な指標が、最も偽陽性を出しやすく、かつ今回は汚染率が90%を超えている。** 流入元フィルタで「YouTube広告」を除外しない限り、この指標は完全に無意味。

### 3-2. 地域構成も同様に汚染される

MiniMax は中国企業であり、自社PR広告を日本国内に限定する理由がない。`HANDOFF.md` §3 では「瞬」の地域構成を 日本 76.8% と記録している。ここが崩れた場合、原因は:

- 広告の海外配信による見かけ上の変化（**実体なし**）
- 自然流入で海外クラスタを掴んだ（**重大な good news**）

これも流入元フィルタでしか切り分けられない。

### 3-3. 判定基準の書き換え

14日後の判定は、**流入元フィルタで「YouTube広告」を除外した自然流入のみ**で行う。広告込みの数値は別枠で記録するが、**移植成否の判断には一切使わない**。

## 4. リスク

### 4-1. 停止のタイミングを制御できない → 数値の崖

MiniMax の都合でキャンペーンは予告なく終わる。終了した瞬間、視聴回数は**9割方が消える**。

**この急落を「動画が失速した」「アルゴリズムに見放された」と誤読しないこと。** 買われていた枠が消えただけである。§5 で広告開始日を記録しておけば、終了時に日別グラフで即座に判別できる。

ただし §2-1 の仮説Aが正しければ、広告終了後も自然配信の一部は残る可能性がある。**キャンペーン終了後2週間の自然流入の推移が、本件で最も価値のあるデータになる。**

### 4-2. ターゲティングが MiniMax の目的に最適化されている

MiniMax が狙うのは「Hailuo で作れる映像の質」の訴求であり、ユーザーのチャンネルを育てることではない。配信先は「**AIツールに関心がある層**」に寄る。

- チャンネルが獲りたいのは「**アニメ／ネタ動画を見る層**」
- 広告が連れてくるのは「**AI生成技術に関心がある層**」

この2つは重なるが同一ではない。**§2-2 のハイプほぼゼロは、まさにこの乖離の現れと解釈できる**——技術として興味深いから最後まで見るが、作品として応援はしない。

**したがって広告経由の登録者増を、そのままチャンネル成長と読まないこと。** 検証は次の動画の「登録者への配信」および「登録者の視聴率」で行う。

### 4-3. 無断使用である点の扱い

MiniMax から事前連絡も事後報告もない。ただし:

- **送客先は自チャンネル**であり、視聴・再生時間・エンゲージメントはすべて自分に計上されている
- 他社予算で約22,575視聴を得ている
- 低評価ゼロ（高評価率100.0%）で、ブランド毀損の兆候もない

**実害がなく、むしろ一方的に利益を得ている状態。争点化する話ではない。**

ただし §5-2 のとおり、**「歓迎している」という立場から接触してデータを要求する**のは筋が通るし、先方にとっても不利益がない。

### 5-2. MiniMax への照会から

広告キャンペーンのデータは **MiniMax の広告アカウント側にしかなく、YouTube Studio からは永久に見えない**。

| 項目 | 価値 |
|---|---|
| **ターゲティング設定**（年齢・地域・興味関心） | **どの層に当てたら刺さったかの直接データ。自力では絶対に取れない** |
| 広告インプレッション数 | §2-5 の検算が即座に終わる |
| 広告の CTR | サムネイル／タイトルの品質を統制条件下で測った値 |
| 配信期間・予算規模 | §4-1 の崖に備える |

MiniMax は**無断で**自社PRに動画を使っている。こちらがそれを歓迎する姿勢を示したうえでレポート共有を求めるのは、先方にとって断る理由がない。さらに、クレジット表記やチャンネルへの導線を交渉する余地もある（「実在のクリエイターが使っている」という訴求は先方にも価値がある）。

## 6. 現時点の結論

1. **広告は止めない・触らない。** インフィード広告は自己選択クリックであり、実測で維持率40%前後を出している。`HANDOFF.md` §7 が禁じた「無関係な外部流入」には当たらない
2. **視聴回数2.5万を成果と読まない。** 9割は他社の買った枠。ハイプが14倍の視聴に対して 4→3 と減っていることが、広告流入の「支持を伴わない」性質を示している（§2-2）
3. **本当の成果は、広告を除いた自然流入が前作の4.6〜7.4倍という点。** ただし原因が「広告の副次効果」か「コンテンツの実力」かは未特定。**§5-1 の日別データが本件で最重要**（§2-1）
4. **コンテンツの保持力は過去最高。** 8:14 で平均視聴時間 3:21。`HANDOFF.md` §5-3 の「尺を切れ」という処方は本作には適用しない（§2-3）
5. **唯一の弱点はイントロ0:30（55%・判定「通常以下」）。** ただし広告流入込みの数字のため、自然流入のみの値を見るまで内容に手を入れない（§2-4）
6. **14日後の判定は広告除外後の自然流入のみで行う。** 特に34歳以下比率は、汚染率90%超の状態で偽陽性を出す（§3-1）
7. **公開先チャンネルを最優先で確認する。** メイン側だった場合、戦略判断が変わる（§5-1 の10）
8. **MiniMax にキャンペーンレポートを要求する。** 自力では絶対に取れないデータであり、依頼が通る立場にある（§5-2）
9. **「広告でアルゴリズムが壊れる／育つ」のどちらの前提でも動かない。** §2-1 の仮説Aは魅力的だが未検証。`HANDOFF.md` §6 で7回繰り返した過剰帰属のパターンを繰り返さない
