# 広告を止めるか、続けるか — 判断文書

作成日: 2026-09-22
前提文書: `HANDOFF.md`（チャンネル戦略分析） / `MINIMAX_ADS.md`（広告出稿の実測分析）
論点: MiniMax による YouTube 広告出稿を、低迷するチャンネルの**カンフル剤**として期待できるか

---

## 0. 結論（先に書く）

| 問い | 答え |
|---|---|
| 広告は止めるべきか | **止めなくてよい。そして実際には止める手段をほぼ持っていない**（§4） |
| 視聴者層の汚染は起きているか | **起きていない。理由は皮肉なことに「登録者が増えていないから」**（§3） |
| 登録者獲得のカンフル剤になるか | **ならない。22,575視聴で純増ゼロという答えが既に出ている**（§5） |
| では価値はないのか | **ある。ただし「集客」ではなく「診断」としての価値**（§6） |
| 低迷の解決になるか | **ならない。低迷の原因は広告で解けない場所にある**（§6-3） |

**最大の発見**: ユーザーが落胆している事実（登録者が増えない）と、ユーザーが恐れているリスク（視聴者層の汚染）は、**同じ一つの事実の裏表**である。登録されていないからこそ、汚染も起きていない。

## 1. リサーチ結果 — YouTube広告と推薦システムの関係

### 1-1. YouTube の公式スタンス: 有料と自然流入は別システム

YouTube は、**広告配信と推薦システムは独立して動作しており、広告予算やターゲティングが自然流入の推薦を増やすことも減らすこともない**としている。

さらに重要な事実として、**YouTube Studio のアナリティクスに「オーガニック／有料」を分離するフィルタが追加されている**（2026年時点）。対象は:

- 視聴回数 / エンゲージド視聴
- 総再生時間 / 平均視聴時間
- 高評価・コメント・共有
- **視聴者維持率**
- **インプレッション および クリック率**

`MINIMAX_ADS.md` §2-6 では「期間を広告配信前で区切る」方法を推奨したが、**この分離フィルタが使えるなら、そちらのほうが直接的で確実**である。広告期間中の自然流入も分離できるため、期間指定より情報量が多い。

> **最優先の実務アクション**: Studio のリーチタブ上部、またはアドバンスモードで「トラフィックソース」のオーガニック／有料フィルタを探すこと。あれば §2-6 の期間指定は不要になる。

### 1-2. 業界の一致した見解 — 害になるのは「人がズレたとき」だけ

複数のソースが同じ条件を挙げている。要約すると:

> **広告が問題を起こすのは、ターゲティングやクリエイティブがズレて「違う人」を連れてきたときだけ。**
> ズレた人が来ると、即離脱・低維持率・セッション時間の低下が起きる。
>
> **逆に、有料の視聴者が自然流入の優良視聴者と同じように振る舞っているなら、推薦は減るのではなくむしろ増える傾向にある。**

これが本件の判断基準そのものになる。**「広告を打ったかどうか」ではなく「来た人がちゃんと見ているかどうか」で決まる。**

### 1-3. インフィード広告は、広告の中では最良の形式

複数のソースが、**インフィード広告（旧ディスカバリー広告）を「本物の登録者獲得における標準」**と位置づけている。検索結果や関連動画の横にサムネイルとして並び、視聴者が自分で選んでクリックするためである。

今回 MiniMax が使っているのはこの形式であり、**広告の中では最も汚染リスクが低い選択**になっている。これは偶然であって MiniMax の配慮ではないが、結果として有利に働いている。

### 1-4. 注意: 「広告が自然配信を加速させる」説は鵜呑みにしない

「広告で高維持率の視聴を集めると推薦エンジンに価値を伝えられ、フライホイールが回る」という主張は複数の記事にあるが、**その多くは広告運用代行業者の発信**である。YouTube 自身は §1-1 のとおり「独立している」としか言っていない。

`HANDOFF.md` §6 で7回繰り返した過剰帰属のパターンに当たるため、**この説を前提に判断を組み立てない。**

## 2. ユーザーの論証の検証 — 2つの根拠のうち、強いのは1つ

ユーザーの主張は「セオリーでは広範囲配信で数字が下がるはずなのに、CTRも平均視聴時間も上がった。だからデータがセオリーを反証している」というもの。**結論は支持できるが、2つの根拠の強さは大きく違う。**

### 2-1. 平均視聴時間の上昇 — これは強い根拠【採用】

平均視聴時間には**広告流入が確実に含まれる**。

```
視聴の90.3%が広告として後から流れ込んだ
        ↓
それでも累積平均は下がらず、0:00 → 約4:15 へ上昇した
        ↓
広告で来た視聴者は、それ以前の自然流入の視聴者を下回っていない
```

母数の9割を占める集団が低品質なら、累積平均は明確に下落したはずである。そうなっていない。

**これは §1-2 の判断基準「有料の視聴者が優良な自然流入と同じように振る舞っているか」に、そのまま YES と答える実測データである。** ユーザーの読みは正しい。

補強として、8:14 という長尺で広告流入の維持率が約40%と逆算される点（`MINIMAX_ADS.md` §2-3）も同じ方向を指している。

### 2-2. CTR の上昇 — これは根拠として弱い【不採用】

**Studio の「インプレッション」が広告インプレッションを含むかどうかが未確定**であり、含まない可能性が高い。含まないなら:

> CTR 4.3%（0% → 6.3% へ上昇）は、**そもそも広告を1件も見ていない指標**である。
> 上昇は自然流入だけの話であり、「広告で薄まらなかった」証拠にはならない。

つまりこの数字は、**それ自体は極めて良いニュース（自然流入の CTR が柳沢2.4%から大きく改善）だが、広告の影響を論じる材料にはならない。**

逆にインプレッションが広告を含んでいた場合、4.3% は広告の CTR に支配されており、やはり自然流入との比較には使えない。**どちらに転んでも、この数字から「広告は汚染しなかった」は導けない。**

§1-1 のオーガニック／有料フィルタ、またはインプレッション実数の検算（`MINIMAX_ADS.md` §2-5）で決着する。

### 2-3. まとめ

**ユーザーの結論「広告は数字を下げていない」は正しい。ただしそれを支えているのは平均視聴時間の1本だけであり、CTR は根拠に数えないほうがよい。** 根拠を2本あると思って判断すると、CTR の分母が判明したときに足元が崩れる。

## 3. 視聴者層の汚染は起きているか — 起きていない

ユーザーが恐れているのは、次の連鎖である。

```
広告でターゲット外の層が流入
        ↓
その層が登録する
        ↓
次回作が「登録者のホーム画面」に配信される
        ↓
興味のない層なのでクリックも視聴もしない
        ↓
初速の数字が死に、配信が絞られる
```

**この機構は実在する。そして本件では、2段目で止まっている。**

> **登録者が増えていない = 汚染の主経路が作動していない。**

`MINIMAX_ADS.md` §2-2 のハイプ分析も同じことを示している。視聴が14倍になってもハイプは 4→3。**広告で来た層は「見る」が「関与しない」ため、チャンネルの視聴者モデルに書き込まれていない。**

さらに:

- **低評価ゼロ**（高評価率100.0%・チャンネル平均96.5%を上回る） → 否定的シグナルも発生していない
- **広告流入の維持率が約40%** → 即離脱による「セッション時間の低下」も起きていない（§1-2 の害の条件に当てはまらない）

### 3-1. ここが本件で最も重要な逆説

ユーザーは「登録者が増えない」ことを不満として、「汚染」を不安として、**別々の問題として書いている。しかしこれは同じ一つの事実である。**

| 見方 | 同じ事実の解釈 |
|---|---|
| 期待する側から見ると | 22,575視聴も来たのに誰も登録しない = **失敗** |
| リスクから見ると | 22,575視聴来ても誰も登録しない = **汚染ゼロ** |

**広告に集客を期待するなら、汚染リスクも同時に引き受けることになる。今は集客がない代わりに、リスクもない。** どちらか片方だけを取ることはできない。

## 4. 「止める」という選択肢は、実は手元にない

判断の前提として確認しておくべき実務上の制約がある。

**この広告は MiniMax のアカウントで、MiniMax の予算で出稿されている。ユーザー側に停止ボタンはない。**

Google Ads では**自分が所有していない公開動画にも広告を出稿できる**ため、止めるには次のいずれかしかない。

| 手段 | 実現性 | 代償 |
|---|---|---|
| MiniMax に停止を依頼する | 連絡先が不明。そもそも先方から連絡がない | 関係構築の機会を自ら潰す |
| 動画を限定公開／非公開にする | 可能 | **`HANDOFF.md` §7 が禁じた行為。** 累積視聴・再生時間・推薦ポジションを失う |
| 何もしない | — | なし |

**「止めるべきか」という問いは、実際には「動画を引っ込めてまで止める価値があるか」という問いになる。§3 の結論（汚染は起きていない）を踏まえれば、答えは明確に NO。**

## 5. カンフル剤として効くか — 登録者獲得としては、効かない

期待に対して率直に書く。**すでに答えが出ている。**

```
広告流入 約22,575視聴
        ↓
登録者の純増 ゼロ
```

n=22,575 は、結論を出すのに十分すぎる標本である。仮に今後キャンペーンが2倍の規模になっても、転換率が同じなら結果は同じ。**この広告は、登録者を連れてこない。**

### 5-1. ただし「純増ゼロ」と「総獲得ゼロ」は違う【要確認】

ここは確認が必要である。**絵空事テレビは広告配信前から登録者が減り続けていた。**

```
減り続けていた  + 広告で少し増えた  =  見かけ上は横ばい（純増ゼロ）
```

という可能性がある。これは「効果ゼロ」とはまったく違う意味を持つ。

> **Studio > アナリティクス > 視聴者 で、登録者数の日別推移を見ること。**
> **広告開始日を境に、減少カーブが平坦化していれば、広告は減少を相殺している。**

平坦化していれば「カンフル剤として部分的に効いている（出血を止めている）」であり、減少カーブが変わっていなければ「完全に無効」である。**この1枚のグラフで判定できる。** `MINIMAX_ADS.md` §5-1 のデータ収集に追加する。

### 5-2. なぜ登録に繋がらないのか

MiniMax の出稿目的は **MiniMax Design のユーザー獲得**である（ユーザー談）。つまりターゲティングは「AIデザインツールに課金しうる層」に最適化されている。

この層は動画を**作品としてではなく作例として**見る。40%まで見るのは「AIでここまでできるのか」という技術的関心であって、「このチャンネルの次回作が見たい」ではない。

**`MINIMAX_ADS.md` §4-2 で立てた「見るが応援しない層」という仮説が、登録者ゼロによって裏付けられた形になる。**

## 6. では何の価値があるのか — 診断としての価値

登録者を連れてこないなら無価値か。**そうではない。低迷の原因究明において、極めて価値が高い。**

### 6-1. 無料で行われた大規模オーディエンステスト

ユーザーは「自信のあるネタもクリック率や視聴時間が上がりきらない」状態にあった。原因が**コンテンツにあるのか、届いていないだけなのか**が切り分けられずにいた。

MiniMax が、それを他社の予算で検定してしまった。

| 検定した問い | 結果 | 意味 |
|---|---|---|
| 人前に出せば見られるのか | **8:14 の動画を約40%まで視聴** | **コンテンツは見られる。「見てもらえば保つ」ことが証明された** |
| 見た人はファンになるのか | 登録ゼロ・ハイプほぼゼロ | **この層はファンにならない** |

**これは「コンテンツが悪いから低迷している」という仮説を棄却する材料である。** 22,575人に見せたら40%まで見た。内容の保持力に問題はない。

### 6-2. したがって低迷の原因は2つに絞られる

1. **リーチ／パッケージングの問題** — 良いものを作っても、そもそも人前に出ていない
2. **「見られる」と「ファンになる」の間の断絶** — 見た人を次に繋ぐ設計がない

**1については、実は既に反証が出ている。** `MINIMAX_ADS.md` §2-1 のとおり、この動画は**広告が始まる前の時点で、自然流入だけで前作の4.6〜7.4倍**を叩き出していた。リーチは前作より明確に改善している。

**したがって残るのは2である。** 見られてはいる。保ってもいる。しかし登録に変換されていない。

### 6-3. 広告はこの問題を解けない

2が原因なら、広告で人を連れてきても意味がない。**穴の空いたバケツに水を注ぐことになる。** 注入量（広告）を増やしても、穴（変換率）は塞がらない。

打つべき手は広告の是非ではなく、次のような変換設計になる。

- 終了画面・カード・再生リストでの次作への導線（`HANDOFF.md` §7 の5・6で既に指摘済み）
- 「このチャンネルは何を出す場所なのか」がチャンネルページで一目で分かる状態か
- 単発で完結する作例ではなく、続きが気になるシリーズ構造になっているか

**これらは `HANDOFF.md` §7 で既に決定済みのアクションと重なる。広告の登場で新しくなった論点ではない。**

## 8. 判断

### 8-1. 広告は継続（＝何もしない）

理由:

1. **害の条件に当てはまらない。** §1-2 の基準「有料視聴者が優良な自然流入と同じように振る舞っているか」に対し、平均視聴時間の上昇と維持率40%が YES と答えている（§2-1）
2. **汚染の主経路が作動していない。** 登録者が増えていない＝視聴者モデルに書き込まれていない（§3）
3. **否定的シグナルもない。** 低評価ゼロ、即離脱なし
4. **止める手段が実質ない。** 止めるには動画を引っ込めるしかなく、それは `HANDOFF.md` §7 の禁止事項（§4）
5. **無料である**

### 8-2. ただし期待の置き所を変える

| 期待 | 判定 |
|---|---|
| 登録者を増やすカンフル剤 | **× 22,575視聴で純増ゼロ。既に答えが出ている**（§5） |
| 減少を相殺する止血剤 | **△ 要確認。日別推移で判定できる**（§5-1） |
| 次回作への追い風 | **× 期待しない。**「広告がアルゴリズムを育てる」説は業者発信が多く、YouTube は独立と明言（§1-4） |
| **低迷の原因究明** | **◎ ここに最大の価値がある**（§6） |

### 8-3. 次にやること（優先順）

1. **Studio のオーガニック／有料フィルタの有無を確認**（§1-1）— あれば以降の計測問題が全部片付く
2. **登録者数の日別推移を見る**（§5-1）— 止血効果の有無が1枚で分かる
3. **公開先チャンネルを確定する**（§7-1）— 戦略判断が変わる
4. **広告除外後の数値一式を記録する**（`MINIMAX_ADS.md` §5-1）— 実写チャンネルの視聴者像を初めて汚染なしで測る
5. **MiniMax にキャンペーンレポートを要求する**（`MINIMAX_ADS.md` §5-2）— ターゲティング設定は §6-1 の診断を完成させる最後のピース
6. **変換設計に着手する**（§6-3）— 広告とは独立に、これが低迷の本丸

## 9. 一行サマリー

> 広告は続けてよい。害が出る条件は「ズレた人が来て即離脱する」ことだが、本件は平均視聴時間が**上がって**おり、広告流入の維持率も約40%あるため、その条件に当てはまらない。汚染を心配する必要もない——**なぜなら誰も登録していないからで、ユーザーが落胆している事実と、恐れているリスクは同じ一つの事実の裏表である。** ただし登録者獲得のカンフル剤にはならない。22,575視聴で純増ゼロという答えが既に出ている。**本当の価値は集客ではなく診断にあり、「22,575人に見せたら40%まで見た」＝コンテンツの保持力に問題はないと確定した。** 低迷の原因は「見られない」ことではなく「見た人が登録しない」ことであり、それは広告では解けない。
