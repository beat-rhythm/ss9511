# チャンネル体制 — ジャンル3分割

作成日: 2026-09-22
前提文書: `HANDOFF.md` / `MINIMAX_ADS.md` / `ADS_DECISION.md`
ステータス: **ユーザーによる決定事項**

---

## 1. 決定した構成

| チャンネル | 担当ジャンル | 現状 |
|---|---|---|
| **メインチャンネル**（＝絵空事テレビ と思われる※） | **実写** | 運用中・登録者数千規模と推定・登録者は減少傾向だった |
| **絵空事アニメ** | **アニメ** | 立ち上げ直後（長尺1本＋Shorts1本）・登録者32人 |
| **不気味の谷のアリス** | **MV** | `HANDOFF.md` に未収録・データ皆無 |

※`HANDOFF.md` §1 は「メインチャンネル」としか記録していない。ユーザーが別途言及した「絵空事テレビ」がこれに当たると解釈している。**要確認。**

### 1-1. 「ヤンキーが運営する遊園地に行ってみた」の所属

**実写チャンネル（メイン）と判断する。** 根拠:

- 「行ってみた」という実写ドキュメンタリー／VLOG の形式を踏襲したタイトル
- MiniMax が Hailuo の生成品質のショーケースとして選んでいる＝**AI生成の実写風映像**である蓋然性が高い
- 高評価率カードに「チャンネルの平均 96.5%」が表示される＝**複数本の実績があるチャンネル**。`HANDOFF.md` §2 時点の絵空事アニメは長尺1本のみで、平均値が出る状態になかった

この判断が正しい場合、**`MINIMAX_ADS.md` §7-1 と `ADS_DECISION.md` §7-1 で最優先としていた「どちらのチャンネルか」は解決する。**

## 2. データはこの分割を強く支持する【本文書の核心】

3分割が正しいことを示す、**チャンネルを固定した対照比較**が既に手元にある。

`HANDOFF.md` §3 の「生成ボタンクリッカー瞬」（アニメ）と、今回の「ヤンキー遊園地」（実写）は、**同じメインチャンネルに投稿されている**。チャンネルの登録者も、蓄積された視聴者モデルも、同一である。違うのはジャンルだけ。

| | 生成ボタンクリッカー瞬（**アニメ**） | ヤンキー遊園地（**実写**） |
|---|---|---|
| 投稿先 | メインチャンネル | メインチャンネル |
| 期間 | 58日 | 9日 |
| 視聴回数 | 約1,796 | 約2,400（**広告を完全に除外した自然流入のみ**） |
| **1日あたり自然視聴** | **約31** | **約267** |

> ### 同一チャンネル・同一視聴者層で、実写はアニメの 約8.6倍 の自然配信を得ている。

しかもこの267は下限である。自然流入が広告開始前の短い期間に集中していたなら、実際の日次はさらに高い（`MINIMAX_ADS.md` §2-1）。

### 2-1. これが決定的な理由

`HANDOFF.md` §5-5 は「メインチャンネルの視聴者が35〜54歳男性に固着しているからアニメが伸びない」と結論した。**この結論は正しかったが、含意が一つ抜けていた。**

前セッションは固着を**欠陥**として扱い、「アニメを別チャンネルへ逃がす」という処方を出した。しかし同じデータは、別の読み方もできる。

> **固着しているのは欠陥ではない。それは「確立された視聴者層」である。**
> **問題はアニメがそこに合っていなかっただけで、合うジャンルを流せば強力な配信装置として機能する。**

実写で8.6倍が出たことが、その証拠になっている。メインチャンネルは壊れていない。**間違った荷物を積んでいただけ。**

### 2-2. 結果として、`HANDOFF.md` §5-5 の移植判断は維持される

読み方は変わるが、処方は変わらない。

- 「瞬」（アニメ）をメインから絵空事アニメへ移す → **そのまま有効**
- ただし理由が変わる。「メインが壊れているから逃がす」ではなく、**「メインは実写の場だから、アニメは本来の場所へ戻す」**

この読み替えは重要である。前者なら「メインは見捨てる」になるが、後者なら**メインは実写の主力として育てる**ことになる。**そしてデータは後者を支持している。**

## 3. 低迷の診断が更新される

`ADS_DECISION.md` §6-2 では「低迷の原因は『見た人が登録しない』変換の問題」と結論した。**3分割という前提が入ると、この診断に補正が要る。**

メインチャンネルの登録者が減り続けていた期間、そのチャンネルには**実写とアニメが混在していた**。つまり:

```
実写を見に来た登録者のホーム画面に、アニメが配信される
        ↓
クリックしない／見ない
        ↓
「このチャンネルの動画は反応が悪い」と学習される
        ↓
実写の配信まで絞られる／登録解除が出る
```

**登録者の減少は、変換設計の不備だけでなく、ジャンル混在そのものが原因だった可能性がある。** だとすれば3分割はそれ自体が治療になる。

ただし `ADS_DECISION.md` §5 の「22,575視聴で登録者の純増ゼロ」は依然として説明を要する。**分割で解決するのは「既存登録者を失う」side であって、「新規が登録しない」side ではない。** 変換設計（終了画面・再生リスト・シリーズ構造）は引き続き別途必要。

## 4. 最大のリスク — 投稿頻度が3分割される

3チャンネル体制で最も現実的な失敗要因はこれである。

`HANDOFF.md` §7 は既にこう書いている。

> **公開は1週間以内。** 柳沢公開から既に9日経過。間隔が空くとチャンネル単位の学習が停滞

そして `HANDOFF.md` §5-1 のとおり、**新規チャンネルは共視聴データがゼロのため探索フェーズに入る**。関連動画が無関係な50本にばら撒かれ、自己修復を待つ期間が必要になる。

**3チャンネルということは、この探索フェーズを3回、並行して走らせるということ。**

```
制作可能本数が 月4本 だとして
  1チャンネル体制 → 月4本。週1。学習が進む
  3チャンネル体制 → 各チャンネル 月1.3本。3週間に1本
                    → どのチャンネルも学習が進まない
```

### 4-1. 推奨: 同時に3つ立ち上げない

**現時点で実績と配信力があるのはメイン（実写）だけである。** 絵空事アニメは長尺1本、不気味の谷のアリスはデータ皆無。

| 優先度 | チャンネル | 理由 |
|---|---|---|
| **1** | **メイン（実写）** | 既に8.6倍の配信力が実証されている。**ここに集中するのが最も費用対効果が高い** |
| 2 | 絵空事アニメ | `HANDOFF.md` §7 の移植プランが進行中。瞬の投入までは既定路線 |
| 3 | 不気味の谷のアリス | **急がない。** 実写が軌道に乗ってからでよい |

3分割は**構造として正しい**が、**3つを同時に育てようとするのは物量的に無理がある**。器を3つ用意することと、3つに均等に注ぐことは別の話である。

**器は今のうちに分けておく（`HANDOFF.md` §5-6 の「今が最も混合コストが安い」がここにも当てはまる）。ただし注力は1つに寄せる。**

## 5. 「不気味の谷のアリス」（MV）固有の論点

データが一切ないため、立ち上げ前に押さえておくべき構造的な違いだけ記す。

MV は YouTube 内で**他ジャンルと配信の力学が異なる**。

- **リピート視聴が主**。維持率や平均視聴率の読み方が実写・アニメと変わる（100%超も起きうる）
- **再生リスト／作業用BGM的消費**が大きい。単発の推薦より「回遊」で伸びる
- **ブラウジング配信が弱く出やすい**。楽曲そのものが動かない限り、推薦面に乗りにくい
- 一方で**検索とサジェストが効きやすい**（曲名・ジャンル名での指名検索）

したがって、実写・アニメで使ってきた判定基準（CTR・平均視聴率）を**そのまま横展開してはいけない**。`HANDOFF.md` §6 の教訓「性質の違う面を混ぜた平均は無効」が、チャンネル間でも当てはまる。

チャンネル名「不気味の谷のアリス」は、AI生成の不自然さを**隠すのではなく看板にする**姿勢であり、ジャンル定義として明確で強い。アルゴリズム上も「何のチャンネルか」が伝わりやすい。

## 7. 一行サマリー

> 実写／アニメ／MV の3分割は構造として正しく、**データも強く支持している——同じメインチャンネルの中で、実写はアニメの約8.6倍の自然配信を得ている**（瞬 31視聴/日 対 ヤンキー 267視聴/日、いずれも広告除外）。これにより `HANDOFF.md` §5-5 の読み方が変わる。メインチャンネルの35〜54歳男性固着は**欠陥ではなく確立された視聴者層**であり、壊れていたのではなく間違った荷物を積んでいただけだった。移植の処方自体は維持されるが、理由は「メインを見捨てる」ではなく「アニメを本来の場所へ戻す」になる。**最大のリスクは投稿頻度の3分割で、器は3つ用意しても注力は実写1本に寄せるべき。** MV は配信の力学が違うため、既存の判定基準を横展開しないこと。
